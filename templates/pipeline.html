NiFi dan Hadoop

NiFi mengambil file bersih dari folder antrean lalu menyimpannya ke HDFS. Halaman ini menunjukkan posisi tiap file dan menjalankan analisis dari data di HDFS.

Koneksi NiFi

Aplikasi membuat dan menjalankan flow GetFile → PutHDFS di NiFi sendiri lewat REST API. Kamu cukup mengisi kredensial NiFi satu kali; setelah itu tiap upload memastikan flow berjalan.

Kredensial NiFi 2.x dibuat otomatis saat pertama jalan: cari kata Generated di <folder-nifi>/logs/nifi-app.log. Disimpan lokal di data/nifi_config.json (tidak ikut ke GitHub).

Antrean NiFi

File di sini menunggu diambil NiFi. Setelah NiFi mengambilnya, file hilang dari antrean dan statusnya berubah menjadi “Sudah di HDFS” (dicek langsung ke HDFS).
